# Variation Normalizer

The Variation Normalizer parses and translates HGVS, gnomAD VCF, and free-text
descriptions of genomic variations into computable objects conforming to the
[GA4GH Variation Representation Specification (VRS)](https://vrs.ga4gh.org/en/latest),
enabling consistent and accurate variant harmonization across a diversity of genomic
knowledge resources.

## Getting started

1. [Start the local API with Docker](installation.md#docker-recommended) or
   [install the Python library](installation.md#python-library).
2. [Try a query](usage.md) using the local API or the Python library.
3. [Check supported nomenclatures](supported_nomenclatures.md) and
   [VRS compatibility](supported_vrs_versions.md) for your data.
4. [Browse the API reference](api/index.md) to integrate normalization into your code.
5. To contribute to the project, follow the [contributing guide](contributing.md).
