# API reference

- [Query handler](query.md): initialize the library and access its operations.
- [Normalization](normalize.md): normalize a query to a prioritized VRS
  representation.
- [VRS translation](to_vrs.md): translate queries without transcript inference.
- [Copy number conversion](to_copy_number_variation.md): construct copy number
  representations from HGVS expressions or parsed components.
- [gnomAD VCF to protein](gnomad_vcf_to_protein_variation.md): translate a
  genomic VCF-style query into a protein representation.
- [HGVS mode handler](hgvs_dup_del_mode.md): interpret deletion and duplication
  expressions. See the [mode guide](../hgvs_dup_del_mode.md) to choose a mode.
